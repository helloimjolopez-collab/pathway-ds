Forces Comic Sans, magenta backgrounds, green text and dashed red borders on * with !important, the way a host app with an aggressive reset or an opinionated component library would. The nav stays untouched: that is Shadow DOM doing its job.

<pathway-sidenav>

One HTML tag. No React on the host page. Works in Radzen, Blazor, Angular, Vue, or plain HTML.

How a team consumes it

<link rel="stylesheet" href=".../tokens/primitives.css">
<link rel="stylesheet" href=".../tokens/themes/light.css">
<script type="module" src=".../pathway-sidenav.js"></script>

<pathway-sidenav active-id="overview" items='[...]'></pathway-sidenav>

Events it emits

nav.addEventListener("pathway-navigate", e => e.detail.id);
nav.addEventListener("pathway-collapse-change", e => e.detail.collapsed);
