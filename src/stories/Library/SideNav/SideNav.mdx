Persistent vertical navigation panel for Ministry Brands Amplify modules. Supports two depth levels (Level 0 parent, Level 1 child-destination), two layout states (expanded 250 px, collapsed 72 px), and three responsive modes (push ≥1024 px, overlay 768–1023 px, hidden-overlay &lt;768 px). Not global app navigation — each module owns its own instance.

The authoritative specification — anatomy, state matrix, design tokens, hover behaviour, popover and tooltip specs, keyboard, screen-reader strings, responsiveness, colour contrast — lives at **`components/sidenav/sidenav-spec.md`**. It is the source of truth for every implementation decision; read it before shipping.
