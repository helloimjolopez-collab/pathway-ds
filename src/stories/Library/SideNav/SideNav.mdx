<Title />

Persistent vertical navigation panel for Ministry Brands Amplify modules. Supports expanded (250 px) and collapsed (72 px) states, two levels of depth (Level 0 parent, Level 1 child-destination), and three responsive modes (push, overlay, hidden-overlay).

Not global app navigation — each module has its own SideNav instance. Not for action buttons or CTAs: navigation only.

---

## Component anatomy

```
SideNav.Container (250px expanded / 72px collapsed)
└── SideNavMenu
│   ├── SideNavItem (Level 0: Destination)
│   ├── SideNavItem (Level 0: Grouper, expanded)
│   │   ├── SideNavItem (Level 1: child Destination)
│   │   └── SideNavItem (Level 1: child Destination)
│   └── SideNavItem (Level 0: Destination)
└── Collapse_Expand_Nav_Container
    ├── Divider
    └── CollapseButton
```

**SideNavItem (Level 0):**
`[indicator 4px][LeadingIcon 24×24][label flex][RowEnd 40×24 — groupers only]`

**SideNavItem (Level 1):**
`[indicator 4px][label flex, pl-32px]` — no icon, always a destination, never a grouper.

## State matrix

| Condition | Fill | Text | Icon | Stripe |
|---|---|---|---|---|
| **Base** | NavItem/Base | NavItem/Base | NavItem/Base | hidden |
| **Hover** | NavItem/Hover | NavItem/Hover | NavItem/Hover | hidden |
| **Active** (destination) | NavItem/Active | NavItem/Active | NavItem/Active | **visible** |
| **Trail: expanded** (grouper is open) | NavItem/Trail | NavItem/Active | NavItem/Base | hidden |
| **Trail: collapsed** (grouper closed, child is active) | NavItem/Active | NavItem/Active | NavItem/Active | **visible** |

Trail-collapsed and Active are visually identical. The only difference is semantic: Active applies to a leaf destination; Trail-collapsed applies to a grouper whose active descendant is hidden.

## Responsive behaviour

| Viewport | Default state | Expanded behaviour | Can be hidden? |
|---|---|---|---|
| &ge;1024 px (Desktop) | Expanded (250 px) | **Push** — content shifts right | No |
| 768–1023 px (Tablet) | Collapsed (72 px) | **Overlay** — 250 px panel floats above content + scrim | No |
| &lt;768 px (Mobile) | **Hidden** | **Overlay** — 250 px drawer triggered by TopNav hamburger | Yes |

## Accessibility

| Concern | Implementation |
|---|---|
| ARIA pattern | `role="tree"` on the nav list; `role="treeitem"` on each item |
| Active page | `aria-current="page"` on the active destination |
| Grouper state | `aria-expanded="true/false"` on groupers only |
| Keyboard | Single tab stop; arrow keys navigate within the tree (Up/Down move, Left/Right expand/collapse) |
| Collapsed labels | Icon-only items need `aria-label` or a visually-hidden span |
| Touch targets | `min-height: 48px` on every item (WCAG 2.5.5) |
