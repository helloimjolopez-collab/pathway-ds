# Org Switcher

> **Status: PLACEHOLDER** — spec is `PENDING HUMAN REVIEW`. Figma node not yet confirmed.
> Token values, spacing, and visual design are hardcoded approximations.
> Do not use in production. Full pipeline will run once the spec reaches `REVIEWED`.

The Org Switcher lets a signed-in user see their active organisation and campus, and switch to a different one. It lives in the global shell (top navigation bar) and is visible at all times in multi-org contexts.

**Desktop:** renders the full organisation name and campus name separated by a pipe.
**Mobile:** renders abbreviated initialisations per the rules in [Appendix A of the spec](../../../components/org-switcher/org-switcher-spec.md).

## Accessibility

- Trigger uses `aria-haspopup="listbox"`, `aria-expanded`, and `aria-controls`.
- The visible abbreviated label is `aria-hidden="true"`; the button's `aria-label` always announces the full org name.
- Panel uses `role="listbox"`; rows use `role="option"` with `aria-selected`.
- Keyboard: `Enter`/`Space` toggles panel; `Arrow Up`/`Down` navigates rows; `Escape` closes.
- Full keyboard spec: [org-switcher-spec.md §13.3](../../../components/org-switcher/org-switcher-spec.md).
