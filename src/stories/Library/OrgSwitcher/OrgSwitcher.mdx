# Org Switcher

The Org Switcher lets a signed-in user see their active organisation and campus, and switch to a different one. It lives in the global shell (top navigation bar) and is visible at all times in multi-org contexts.

**Desktop:** renders the full organisation name and campus name separated by a pipe.
**Mobile:** renders abbreviated initialisations per the rules in [Appendix A of the spec](https://github.com/helloimjolopez-collab/pathway-ds/blob/main/components/org-switcher/org-switcher-spec.md#appendix-a-abbreviation-guidelines).

**Always on the brand-blue surface.** All interactive controls use dark-mode tokens regardless of the app's active color scheme.

**Spec:** `components/org-switcher/org-switcher-spec.md` · **Figma:** [Open node 40007336-9453](https://www.figma.com/design/3sw45aVcngFAmpbP6cfrXP/?node-id=40007336-9453)

## Panel — open state

When `open={true}`, a panel renders below the trigger at `top: calc(100% + 4px)`. It contains a header, a search bar, and a scrollable list of organisations. The active org is highlighted in blue. Clicking an org fires `onOrgSelect(orgId)`.

## Mobile layout

On viewports below 768px (or when `mobile={true}` is forced), the label switches to the abbreviated format. The panel is the same as desktop.

## No logo — initials fallback

## Design tokens

All colours on the trigger and panel are resolved through semantic tokens.

| Token | Resolved | Usage |
|---|---|---|
| `semantic-color.dark-mode.fill.action.tertiary.base` | `rgba(160,181,230,0.04)` | Trigger base fill |
| `semantic-color.dark-mode.stroke.action.tertiary.base` | `rgba(160,181,230,0.16)` | Trigger border base |
| `semantic-color.dark-mode.stroke.action.tertiary.hover` | `rgba(160,181,230,0.20)` | Trigger border hover |
| `semantic-color.dark-mode.stroke.action.tertiary.pressed` | `rgba(160,181,230,0.30)` | Trigger border open/pressed |
| `semantic-color.dark-mode.fill.action.primaryinverse.hover` | `rgba(10,18,35,0.16)` | Trigger hover fill |
| `semantic-color.dark-mode.fill.action.primaryinverse.pressed` | `rgba(255,255,255,0.08)` | Trigger open/pressed fill |
| `semantic-color.dark-mode.text.action.mono.base` | `#fbfbfb` | Trigger label + chevron |
| `semantic-color.light-mode.fill.static.brand.base` | `#2d4889` | Org logo branded bg (no logo) |

> All token values are sourced from `src/tokens/tokens.css`. Never hardcode hex values in component code.

## Panel anatomy

The panel (316px wide, `z-index: 300`) contains:

1. **Header** — "My Organizations", 14px/600, `#252525`, padding `16px 16px 12px`
2. **Search bar** — pill shape, `#f4f4f4` background, `#e0e0e0` border, 36px height, Material Symbol `search` icon
3. **Org list** — scrollable, max 320px. Each row: 48×48 logo → org name + campus → user avatar stack → `chevron_right`
4. **Active org** — highlighted `#eef2fb` background
5. **Entrance animation** — `orgPanelIn` 200ms `cubic-bezier(0,0,0.2,1)`, `translateY(-6px) → 0`
6. **Shadow** — `0 8px 24px rgba(0,0,0,0.12), 0 2px 6px rgba(0,0,0,0.06)`

## Accessibility

- Trigger uses `aria-haspopup="true"`, `aria-expanded`, and an `aria-label` that always announces the full org name.
- On mobile, the visible abbreviated label is separate from the button's `aria-label`, which carries the full unabbreviated name.
- Panel uses `role="dialog"` with `aria-label="Switch organisation"`. Org list uses `role="listbox"`.
- Keyboard: `Enter`/`Space` toggles panel; `Escape` closes (wire up in the parent shell's keydown handler).
- Focus ring: `2px solid rgba(255,255,255,0.9)` on the trigger button.
- All interactive controls have 48×48px outer touch targets (WCAG 2.5.5).
- Chevron rotation: `transform 200ms cubic-bezier(0.4,0,0.2,1)` — follows `prefers-reduced-motion` override if implemented at the shell level.
