# Org Switcher

The Org Switcher is the trigger that sits in the brand-blue top nav and shows the active organisation. Clicking it opens a panel for switching between orgs the user has access to.

<p style={{ padding: "10px 14px", background: "#fff7e0", borderLeft: "3px solid #e6a700", borderRadius: 4, margin: "16px 0", fontSize: 13, color: "#5b4500" }}>
  <strong>v1 scope — trigger only.</strong> This release covers the trigger control. The drop panel exists in the repo as a working placeholder so the trigger can open against something, but it is <strong>not part of the design system yet</strong> and its visual is non-authoritative. The panel will get its own design pass in a later version. See <code>org-switcher-spec.md</code> §0.
</p>

## Desktop variants

The trigger renders inside the brand-blue top nav. The org name is left-aligned, truncates with ellipsis at 180px, and Catholic organisations get a second city/diocese container after a pipe.

<Canvas of={OrgSwitcherStories.DesktopVariants} />

## Catholic vs Protestant — the CityName rule

Per spec §0.1, `Container.CityName.Catholic` is **only ever rendered for Catholic organisations**. Protestant orgs render the org name on its own — no pipe, no second container — even if a `cityName` string is supplied.

The rule is enforced in code by the `orgType` discriminant:

```jsx
const showCityName = orgType === "catholic" && Boolean(cityName);
```

## Truncation

`Container.OrgName` is content-sized with `max-width: 180px`. Short org names ("Cross Point") shrink the container to fit. Long names truncate with ellipsis at 180px.

<Canvas of={OrgSwitcherStories.Truncation} />

## Mobile

On viewports below 768px (or when `mobile={true}` is forced), the trigger compacts to a fixed 108px-wide pill. The label container is a fixed 50px wide and the full org name truncates inside it with ellipsis. **No abbreviation.** Typography is `Label/Button/S` (14px) — same as desktop.

## Motion

| Property | Value |
|---|---|
| Chevron rotation | `transform 200ms cubic-bezier(0.4,0,0.2,1)` |
| Hover/pressed transitions | `background 120ms ease, border-color 120ms ease` |
| Reduced motion | Snap (no easing) when `prefers-reduced-motion: reduce` |

---

## Accessibility

- Trigger is a real `<button>` with `aria-haspopup="true"` and `aria-expanded` reflecting the open state
- `aria-label` always carries the full org name, even when the visible label is truncated
- For Catholic orgs, the city name is included in the aria-label as well (`"Current organisation: Sacred Heart Church-ITD, Knoxville. Activate to switch."`)
- Outer touch target is 48×48 (WCAG 2.5.5)
- Disabled state (single-org users) sets `aria-disabled` via the native `disabled` attribute
- Reduced motion: chevron rotation drops to instant when `prefers-reduced-motion: reduce` is set at the shell level
