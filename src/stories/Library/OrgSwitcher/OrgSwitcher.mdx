# Org Switcher

The Org Switcher lets a signed-in user see their active organisation and campus, and switch to a different one. It lives in the global shell (top navigation bar) and is visible at all times in multi-org contexts.

**Desktop:** renders the full organisation name (max 170px). For Catholic orgs only, a second container shows the city/diocese name (max 72px) after a pipe.
**Mobile:** renders the full organisation name truncated by `text-overflow: ellipsis` at `Container.Label` max-width 60px. No abbreviation — "Grace Community Church" displays as "Grace Comm…".

**Always on the brand-blue surface.** All interactive controls use dark-mode tokens regardless of the app's active color scheme.

## Panel — open state

When `open={true}`, a panel renders below the trigger at `top: calc(100% + 4px)`. It contains a header, a search bar, and a scrollable list of organisations. The active org is highlighted in blue. Clicking an org fires `onOrgSelect(orgId)`.

## Mobile layout

On viewports below 768px (or when `mobile={true}` is forced), the trigger compacts to a 108px max-width pill. The avatar shrinks to 20×20 outer (16×16 inner) and the org name is rendered in `Label/Button/XS` (12px / 500 / 18px lh), truncated by CSS `text-overflow: ellipsis` at `Container.Label` max-width 60px. **No abbreviation** — the full org name is the source string, truncated visually.

| `semantic-color.dark-mode.stroke.action.tertiary.pressed` | `rgba(160,181,230,0.30)` | Trigger border open/pressed |

## Panel anatomy

The panel (414px wide on desktop, 380px on mobile, `z-index: 300`) contains:

1. **Header** — "My Organizations" breadcrumb, `Red Hat Text SemiBold 14px / color #6b6b6b`, padding `px:10 py:4` inside a rounded-4 container
2. **Search bar** — bordered rectangle (not pill), `1px solid #b5b5b5`, `rounded-4`, padding `8px`. 24×24 search icon + 16px Regular `Search` placeholder
3. **Org list** — scrollable, `gap: 16px` between rows. Each row is 78px tall:
   - 64×46 RECTANGULAR logo (navy `#0f3e80` background, `rounded-4`, logo image scaled `object-fit: contain`)
   - Org name (`Red Hat Text SemiBold 14/22 #363636`)
   - **Module icons row** — small 18×18 colored chips showing which Pathway modules the org subscribes to (people, giving, app-builder, etc.). Chips overlap by 2px with a 1.5px white border each
   - `chevron_right` icon on the right
4. **Active org** — highlighted `#eef2fb` background
5. **Entrance animation** — `orgPanelIn` 200ms `cubic-bezier(0,0,0.2,1)`, `translateY(-6px) → 0`
6. **Shadow** — `0 8px 24px rgba(0,0,0,0.12), 0 2px 6px rgba(0,0,0,0.06)`

## Accessibility

- Trigger uses `aria-haspopup="true"`, `aria-expanded`, and an `aria-label` that always announces the full org name.
- On mobile, the visually-truncated label is separate from the button's `aria-label`, which carries the full org name.
- Panel uses `role="dialog"` with `aria-label="Switch organisation"`. Org list uses `role="listbox"`.
- Keyboard: `Enter`/`Space` toggles panel; `Escape` closes (wire up in the parent shell's keydown handler).
- Focus ring: `2px solid rgba(255,255,255,0.9)` on the trigger button.
- All interactive controls have 48×48px outer touch targets (WCAG 2.5.5).
- Chevron rotation: `transform 200ms cubic-bezier(0.4,0,0.2,1)` — follows `prefers-reduced-motion` override if implemented at the shell level.
