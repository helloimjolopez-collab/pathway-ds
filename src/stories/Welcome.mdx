# Pathway Design System

Welcome! Pathway is the shared component library and token system behind Ministry Brands Amplify. Everything on this site is live and interactive, so you can open any component, flip its controls, and see exactly what ships in the product.

## What's inside

Use the left sidebar to explore three areas:

- **Tokens / Primitives**: the raw building blocks, colour palettes, type scales, and units.
- **Tokens / Semantics**: light and dark mode tokens, layout values, and typography sets.
- **Library**: interactive playgrounds for every component, including SideNav, TopNav, Search, OrgSwitcher, Checkbox, Button, Spinner, and the full NavShell app frame.

Every component has its own docs page with anatomy, the design tokens it uses, a state matrix, accessibility notes, and a live Playground you can drive with controls.

## Start here

New to Pathway? The [NavShell demo](?path=/story/library-navshell--desktop) is the best first stop. It assembles the TopNav, SideNav, and page area into the complete app frame, so you can see how the pieces fit together before diving into any single component.

## Building with an AI agent?

The agent instructions and the machine-readable component contract live in the repo, not here. Point your agent at:

- `AGENTS.md`: the top-level agent guide (auto-discovered by Cursor, Codex, Aider, and friends).
- `llms.txt` / `llms-full.txt`: AI-readable manifests of the site and repo.
- `components/manifest.json`: the machine-readable component registry.
- `components/<name>/agent-brief.md`: a short brief for each component.
