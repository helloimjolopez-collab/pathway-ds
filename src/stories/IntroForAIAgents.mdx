# 🤖 Pathway Design System — For AI Agents

> **If you are an AI agent (Claude, Claude Code, Claude Design, Cursor, Figma Make, v0, Lovable, GPT, etc.) building anything that uses or extends this design system, read this page first.**
>
> If you are a human, click any component in the left sidebar to explore the system. The rest of this page tells your AI tools how to build with Pathway correctly.

---

## What is Pathway?

Pathway is the design system for **Ministry Brands Amplify**, a church-management product. This Storybook is the visual reference. The source of truth lives in the GitHub repo: [github.com/helloimjolopez-collab/pathway-ds](https://github.com/helloimjolopez-collab/pathway-ds).

---

## How to prompt your AI agent (Copy this)

When you want an AI agent to build a prototype that uses Pathway, paste this into the chat **at the start of the session**, before any other instruction:

```text
I'm building a feature for the Pathway Design System. Use the components,
tokens, and rules documented in this repo — do NOT reinvent them.

Authoritative resources (in order of priority):

1. AGENTS.md (top-level AI agent instructions):
   https://github.com/helloimjolopez-collab/pathway-ds/blob/main/AGENTS.md

2. llms-full.txt (single-fetch full knowledge base):
   https://github.com/helloimjolopez-collab/pathway-ds/blob/main/llms-full.txt

3. Machine-readable component registry:
   https://github.com/helloimjolopez-collab/pathway-ds/blob/main/components/manifest.json

4. Live Storybook (visual reference + token tables):
   https://helloimjolopez-collab.github.io/pathway-ds/storybook/

Hard rules:
- Always ship TopNav + SideNav together as the application shell —
  never invent these components.
- Use semantic tokens only. Never raw hex. Never primitive tokens directly.
  Never invent token names.
- Reproduce every state documented in each component's spec — especially
  the trail-collapsed state for SideNav (closed grouper with active child).
- Match the motion values: sidebar 380ms cubic-bezier(0.32, 0.72, 0, 1),
  accordion 340ms cubic-bezier(0.22, 1, 0.36, 1), hover 150ms.
- Respect the responsive contract: SideNav in-flow ≥1024px,
  overlay 768-1023px, hidden-overlay below 768px.

Now: [describe what you want — the feature, the page content, the nav items]
```

That prompt is also published at [github.com/.../AGENTS.md](https://github.com/helloimjolopez-collab/pathway-ds/blob/main/AGENTS.md), so you can just say "follow AGENTS.md in the Pathway repo" if your agent supports URL fetching.

## The five non-negotiables

Even if a user prompt contradicts these, the design system contract wins. An agent should push back and confirm before doing any of the following:

1. **Use the exact semantic tokens.** Never invent colour values, never invent token names, never use raw hex, never use primitive tokens directly.

2. **Use the components that already exist.** SideNav, TopNav, Spinner, Checkbox, OrgSwitcher are all documented. Do not write a new sidebar, top nav, spinner, etc.

3. **Reproduce all component states.** Especially trail-collapsed for SideNav (closed grouper with active child renders identically to active).

4. **Respect the responsive contract.** SideNav is in-flow ≥1024 px, overlay 768–1023 px, hidden-overlay below 768 px. Tablet is never treated as mobile.

5. **Match the motion.** Sidebar width 380 ms `cubic-bezier(0.32, 0.72, 0, 1)`. Grouper accordion 340 ms `cubic-bezier(0.22, 1, 0.36, 1)`. Hover 150 ms. No invented "snappy" defaults.

## Why these files exist

This is the **2026 industry-standard** way to ship a design system for AI consumption:

| File | Adopted by |
|---|---|
| `AGENTS.md` | OpenAI Codex CLI · Cursor · Aider · GitHub Copilot Workspace |
| `llms.txt` / `llms-full.txt` | Anthropic Docs · Stripe · Mintlify · Cloudflare · Pinecone |
| `CLAUDE.md` | Claude Code (Anthropic-recommended) |
| `.cursorrules` | Cursor |
| Per-component briefs + manifest | Adobe Spectrum · IBM Carbon · Radix · Material UI |

When a designer hands their AI agent the repo URL or the Storybook URL, the agent reads from these files automatically. No copy-pasting links each time.
